# Downloaded spell cues

Five unmodified WAVs from **Kenney Interface Sounds 1.0**, licensed **CC0**.
Official source: https://kenney.nl/assets/interface-sounds
Download mirror: https://github.com/Calinou/kenney-interface-sounds

The original license is `LICENSE.txt`; `sources.json` records original filenames, durations and SHA-256 hashes. Files are renamed for their in-game purpose, with no synthesis, generation or audio edits. Names describe routing, not the original pack categories.

| Game cue | Original file | Used for |
|---|---|---|
| spore | pluck_001.wav | Champignon casting/guardian blocks |
| thorn | scratch_003.wav | Bramble casting/guardian blocks |
| portal | maximize_007.wav | Andromoss casting/magic rabbit arrivals |
| whisper | minimize_004.wav | Duskmantle casting/marked misses/rewarded souls |
| leaf | glass_004.wav | Sprig casting/extended arrivals/ward blocks |

Existing recovered hits, stars, armor impacts and sweep sounds remain. Closely spaced thematic cues are coalesced, muted events are consumed, and all audio remains under the existing voice cap. No additional dependency, service or paid audio generator is required.
