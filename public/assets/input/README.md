# Input artwork

Cropped without resizing or repainting from the user-supplied CraftPix “Keyboard and Mouse Free Pixel Art Asset Pack” (726651). Only controls used by this game are included.

Keyboard: PNG/Kb_buttons_standart_frame_white.png, 16×16 light keycaps. Mouse: PNG/Mouse_base.png, first white 64×80 mouse.

Original License.txt is preserved. Freebie game-use terms: https://craftpix.net/file-licenses/ (section 2). Assets are integrated game controls, not an asset-export feature. No generation was used.

The blank cap is cropped from Kb_blank_buttons_animation_white.png. A code-drawn plus marks the secondary character-confirm key, avoiding the source atlas’s combined plus/equals symbol.

Menu controls reuse the unmodified standard-frame atlas as menu-keys.png: Esc (0,0,16×16), Enter (64,96,32×16), Left/Right (0/16,80,16×16), rendered through clipped SVG viewports. No new image was drawn. Decorative key hints are hidden on touch-primary devices; arrow buttons remain usable.

Magic now uses Tab and Numpad Enter. The existing blank cap carries a small Tab text label; the existing Enter atlas glyph is reused with the explicit Numpad Enter accessible label. No new raster artwork or generation.
