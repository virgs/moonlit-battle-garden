# Bundled fonts

- **Almendra**, Ana Sanfelippo: regular and bold, from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/almendra).
- **Cinzel**, Natanael Gama: variable upright face (weight 400–900), used for the pause title, from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/cinzel).
- **Literata**, TypeTogether: variable upright face (weight 200–900, optical size 7–72), from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/literata).

Downloaded November 16, 2026. Original font files are unmodified. All use the SIL Open Font License 1.1; each directory includes its original `OFL.txt` copyright and license. CSS imports let Vite fingerprint and rebase the files for GitHub Pages. No external font requests are required.
